# eDorado — публичные материалы

Открытые инструменты и материалы eDorado. Здесь нет секретов и внутренних данных: всё можно свободно скачивать и использовать (лицензия MIT, см. [LICENSE](LICENSE)).

## Содержимое

| Папка | Что это |
|---|---|
| [github-raw-inline](github-raw-inline/) | Расширение для Vivaldi, Chrome и других браузеров на Chromium: видео, PDF, картинки и текстовые файлы из репозиториев GitHub открываются в новой вкладке, а не скачиваются |
